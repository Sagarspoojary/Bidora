PHASE 2 — AUTHENTICATION & USER MANAGEMENT

STATUS:
COMPLETED

OBJECTIVE:
Implement the complete Authentication and User Management foundation for the Bidora Online Auction System, including database tables, password security, JWT middleware, secure routes, profiles, and state-integrated glassmorphic UI forms.

IMPLEMENTATION:
Created PostgreSQL table with UUIDs, email constraints, and index mappings. Built secure registration, logins, session state retrievals, profile changes, and password change systems on Node.js/Express. Created a state-based SPA hash router on the frontend and tied all authorization flows to a global AuthContext. Added a premium glassmorphic Framer Motion intro logo screen, leading straight to authentication routes once finished. Added Nodemailer SMTP integration for delivering password reset emails.

DATABASE CHANGES:
Created "users" table in PostgreSQL:
- id (UUID PRIMARY KEY DEFAULT uuid_generate_v4())
- name (VARCHAR NOT NULL)
- email (VARCHAR UNIQUE NOT NULL, INDEXED)
- password_hash (VARCHAR NOT NULL)
- avatar_url (VARCHAR NULL)
- role (VARCHAR DEFAULT 'USER')
- status (VARCHAR DEFAULT 'ACTIVE')
- reset_token (VARCHAR DEFAULT NULL)
- reset_token_expires (TIMESTAMP WITH TIME ZONE DEFAULT NULL)
- created_at, updated_at, last_login_at (TIMESTAMPS)

API ENDPOINTS:
- POST /api/auth/register (New registration, handles duplicate emails & validations)
- POST /api/auth/login (Authenticates credentials, generates JWT, updates last login time)
- POST /api/auth/logout (Confirms logout session cleanup)
- GET /api/auth/me (Retrieves safe session details using token verification)
- PUT /api/auth/profile (Updates display name and avatar)
- PUT /api/auth/change-password (Updates password after comparing old password hash)
- POST /api/auth/forgot-password (Generates reset token, updates DB, sends SMTP email/console link)
- POST /api/auth/reset-password (Verifies token validity, updates password_hash, clears tokens)

FRONTEND:
- AuthContext: Exposes user state, login, register, logout, update profile, and change password methods.
- ProtectedRoute: Intercepts unauthenticated hash changes to #/profile and redirects to #/login.
- Login & Register Pages: Render glassmorphic cards with responsive layout, inputs, show/hide passwords, loading states, and error alerts.
- Profile Page: Enables display updates and secure password rotation settings.
- IntroLogo Screen: High-end cinematic entrance with letters of BIDORA scaling, and glass icon floating via Framer Motion.
- Forgot & Reset Password views integrated inside the main Auth card.

SECURITY:
- Password storage encrypted using bcrypt with salt rounds factor = 12.
- JWT verification checking active/suspended account state.
- Injection prevention using PostgreSQL parameterized queries.
- Disallowed modifications of status and roles from client profile forms.

ENVIRONMENT VARIABLES:
- JWT_SECRET (loaded from .env for signing tokens)
- JWT_EXPIRES_IN (default: '1d')
- GOOGLE_CLIENT_ID (for Google OAuth)
- GOOGLE_CLIENT_SECRET (for Google OAuth)
- EMAIL_USER (for SMTP sender email)
- EMAIL_PASS (for SMTP App Password)
